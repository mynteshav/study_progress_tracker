# 📚 Study Progress Tracker

> An all-in-one productivity application designed to help students plan, track, and improve their learning journey.

🌐 **Live Demo:** https://study-progress-tracker-ct5fhezpq-teshavs-projects-ce236c35.vercel.app/

---

## 🚀 Overview

Study Progress Tracker is a modern productivity application that helps students stay organized, monitor study habits, and achieve their learning goals.

The application combines study planning, focus sessions, progress analytics, habit tracking, flashcards, and project management into a single intuitive dashboard.

---

## ✨ Features

### 📊 Dashboard
- Daily study overview
- Total study hours
- Completed tasks
- Productivity KPIs
- Progress statistics

### ⏱️ Focus Timer (Pomodoro)
- Custom study timer
- Pause / Resume / Reset
- Save completed study time
- Automatically updates daily study hours

### 📅 Timetable
- Create study schedules
- Weekly planner
- Apply timetable to all days
- Edit and delete schedules

- Daily study statistics
- Weekly progress

- Interactive charts

### ✅ Task Management
- Add study tasks

### 📝 Notes
- Create notes

- Quick editing

### 🧠 Flashcards
- Create flashcards
- Review concepts
- Improve memory retention

### 🎯 Habit Tracker
- Track daily habits

- Track solved coding problems

### 📂 Project Tracker
- Manage personal projects
- Track project status

### 🌙 Modern UI
- Responsive interface

- User-friendly experience

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/study-progress-tracker.git
```

Move into the project

```bash
cd study-progress-tracker
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build the project

```bash
npm run build
```

Run Electron

```bash
npm run electron
```

# 📈 Why This Project?

This application was built to solve a common problem faced by students—managing multiple productivity tools.

Instead of switching between different applications for timers, notes, tasks, analytics, and schedules, Study Progress Tracker provides everything in one unified platform.
